## 4. Выжимка для дизайн-агента (правила)

- **Цвет.** База — графит `#0F0F10` / антрацит `#1A1A1C` / тёплый серый `#2A2A2A`. Акцент — сигнальный оранжевый касок `#FF5A1F` (один, строго один). Текст — тёплый белый `#F2F0ED`. Никакого зелёного (дерево ≠ эко-клише), никакого голубого (небо ≠ альпинист).
- **Типографика.** Жёсткий индустриальный гротеск для заголовков: Druk / Monument Grotesk / PP Neue Machina / Space Grotesk (бесплатная альтернатива). Hero-заголовок = 10–14 vw, вес 700–900. Моноширинный для ТТХ, цифр и меток: JetBrains Mono / IBM Plex Mono.
- **Фото.** Только реальные кадры с объектов папы: альпинист на стволе, бензопила в работе, крупный план карабинов и строп, вышка с вылетом, грязный ботинок на коре. Никакого стока. Минимум ретуши, естественный контраст. Фото — на весь экран, 60–80% высоты вьюпорта.
- **Сетка.** 12-колоночная с крупными gutters (24–32px). Hero — асимметричный (большой заголовок слева, фото справа без рамки до края экрана). Сервисные карточки — крупные, 2×2 или 3×2, с живыми фото, не иконками.
- **UI-детали.** Технические насечки (`||||`), моноширинные метки `[SPIL-01]` или `№004 / СПИЛ`, тонкие линии-разделители (1px, `#2A2A2A`), таблицы ТТХ для вышки (моноширинный шрифт, цифры в правом столбце), статус-бейджи вроде `24/7` в рамке.
- **CTA.** Один доминирующий — оранжевая плашка с жирным гротеском, стрелка-уголок. На тёмном фоне. Второстепенные — текстовые ссылки с подчёркиванием. Телефон крупный, фиксированный, кликабельный.
- **Анимация.** Сдержанная: scroll-triggered появление блоков снизу, лёгкий parallax на фото, hover-состояния на карточках (сдвиг на 4–8px + смена оттенка). Никаких крутящихся логотипов, частиц, scroll-hijacking.
- **Табу.** Градиенты, стоковые фото, зелёный, голубой, карусели услуг на главной, попап-формы при входе, счётчики «осталось N мест», слоганы в капслок с восклицательными, иконки-смайлики, «эко-френдли» риторика, корпоративный пафос «лидеры рынка».
- **Структура главной (многостраничник).** Hero с флагманом (спил) → доверие (цифры: лет, объектов, бригад) → услуги в 6 карточек → кейсы с before/after → процесс работы (линия из 5 шагов) → автовышка-блок с ТТХ-таблицей → отзывы с реальными именами → FAQ по порубочному билету/страховке → CTA + контакты.
